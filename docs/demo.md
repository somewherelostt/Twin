# Twin demo

## Clean dictation

1. Open any text field and press `Alt+Space`.
2. Choose **Dictate** and speak with a filler word and a self-correction.
3. Stop the recording, compare the original transcript with the clean version, then paste it into the previous app.

## Screen-aware action

1. Open a GitHub issue or a visible error report and press `Alt+Space`.
2. Choose **Act** and say: “Create a Jira ticket for this, link the GitHub issue, and tell the engineering channel in Slack.”
3. Review the resolved context and every external effect on the action card.
4. Press **Run action** and show the completion receipt.

## Suggested fallback

Use a direct request when the visible page has little context: “Email alex@example.com a summary of issue 42 in the acme/web repository.”
